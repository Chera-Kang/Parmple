## 3. 상세 테스트 케이스 명세

### TC-FIGMA-01-001: 사업자등록번호 경계값/유효성 방어 단언
- **Figma Node**: `Sample TC > 회원가입 > 사업자등록번호 입력 (1:284)`
- **테스트 절차**:
  1. `BASE_URL` 접속 ➔ `회원가입` 링크 클릭
  2. "사업자등록번호를 입력해 주세요" 문구 노출 확인
  3. 10자리 미만(예: 5자리 `12345`) 입력 시 `[확인]` 버튼 비활성화(disabled) 단언
  4. 유효 사업자등록번호(10자리) 입력 시 `[확인]` 버튼 활성화(enabled) 단언
- **예상 결과**: 자리수 미달 시 확인 버튼 비활성화로 무효 입력 방어 완료

### TC-FIGMA-01-003: 신규 회원가입 폼 작성 ➔ 로그인 ➔ 프로필 1:1 데이터 연동 E2E
- **Figma Node**: `Sample TC > 회원가입` ➔ `로그인 Page` ➔ `내 정보 (21:9533)`
- **테스트 절차**:
  1. 사업자번호 입력 ➔ 모달 확인 ➔ 사업자등록증 및 판촉영업신고증 파일 첨부
  2. 계정 정보(이메일, 비밀번호, 이름, 휴대폰번호) 입력 ➔ 약관 전체 동의 클릭
  3. `[가입하기]` 버튼 활성화 단언
  4. 로그인 페이지로 이동하여 CSO 계정 로그인
  5. GNB 우측 상단 `[내 정보]` 클릭 ➔ `내 정보` 페이지 이동 (`/dashboard/my-info`)
  6. 가입 시 입력된 계정 정보(이름, 번호, 아이디) 및 사업자 정보(업체명, 대표자, 사업자번호 등) 1:1 데이터 매핑 단언
- **예상 결과**: 가입 폼 데이터가 프로필 화면에 100% 일치하여 노출됨

### TC-FIGMA-01-004: [프로필 > 계정 관리] 하위 메뉴 및 모달/팝업 전체 검증
- **Figma Node**: `Sample TC > 내 정보 > [SECTION] 계정 관리 (21:11717)`
  - `계정 정보 수정 (21:11781)` / Description: `이름 : 테스트_mmdd-hhmm, 휴대폰 번호 : 010-xxxx-xxxx 난수 입력`
  - `비밀번호 변경 (21:11779)` / Description: `현재와 같은 비밀번호로 변경하여 확인`
  - `회원 탈퇴 (21:11773)` / Description: `회원탈퇴는 진행하지 않고 팝업 발생 여부만 확인`
- **테스트 절차**:
  1. CSO 로그인 ➔ `내 정보` 페이지 진입

  3. **계정 정보 수정**: `[계정 정보 수정]` 클릭 ➔ 모달 오픈 단언 ➔ 이름(`테스트_mmdd-hhmm`), 휴대폰번호(`010-xxxx-xxxx`) 입력 필드 가시성 및 입력 동작 검증 ➔ `[취소]` 클릭하여 모달 닫기
  4. **비밀번호 변경**: `[계정 관리]` ➔ `[비밀번호 변경]` 클릭 ➔ 모달 오픈 단언 ➔ 비밀번호 입력 필드 확인 ➔ `[취소]` 클릭하여 닫기
  5. **회원 탈퇴**: `[계정 관리]` ➔ `[회원 탈퇴]` 클릭 ➔ 경고 알럿("정말 탈퇴하시겠어요") 노출 단언 ➔ 실제 탈퇴 미진행 원칙에 따라 `[취소]` 클릭하여 닫기
- **예상 결과**: 계정 관리 하위 3개 모달/팝업이 피그마 명세대로 정상 렌더링 및 취소 동작 완료
